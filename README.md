# Accessibility Analyser — Full-Stack (Pro)

## What is this?
A professional, responsive full-stack Accessibility Analyser built for portfolio and resume. 
Frontend (React + Vite + Framer Motion + Tailwind CDN), Backend (Node.js + Express).
Rule-based AI-style suggestions, file upload, history, and export.

## Run locally

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```

Open the URL shown by Vite (usually https://vercel.com/shalini500s-projects/accessibility-analyser-fullstack-m7ge/4W6BRwv9fbWzkb4MEhAGWkWZzjh4)

## Notes
- No external APIs required. Suggestions are rule-based.
- For production, consider securing backend and persisting history to a DB.
