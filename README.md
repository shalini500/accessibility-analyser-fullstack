# ♿ Accessibility Analyser — Full-Stack (Pro)

## What is this?
A professional, responsive full-stack Accessibility Analyser built for portfolio and resume.

**Frontend:** React + Vite + Framer Motion + Tailwind  
**Backend:** Node.js + Express  

The project provides rule-based, AI-style accessibility suggestions, scoring, history tracking, and export features.

---

## 🚀 Live Demo
https://accessibility-analyser-fullstack-m7.vercel.app/

> Note: The live demo runs the frontend only.  
> Backend and local AI (Ollama) are intended to run locally.

---

## ✨ Features
- Paste HTML or upload `.html` file
- Accessibility issue detection
- AI-style explanations and suggestions
- Accessibility score
- Analysis history
- Copy & download analysis report
- No paid APIs required
